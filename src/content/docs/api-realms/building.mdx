Buildings (AKA campuses), are further separations of courses, groups, and users that all belong to the same system.

## Fields

Buildings use the same fields as [schools](../school), although may have a `building_code`, a configurable external ID string (used for imports and synchronization).

## GET, PUT, DELETE `schools/{id}`

Buildings use the same endpoints as [schools](../school) for GET, PUT, and DELETE.

## POST `schools/{school id}/buildings`

Create a building in a school

**Content** A [building](#fields)
